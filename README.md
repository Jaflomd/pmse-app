# Intake Unificado Deploy

Static GitHub Pages package built from:

`3-output/unified-intake/backups/unified-intake`

The published root `index.html` and `intake-unificado.html` both open the
production `intake-unificado.html` from that folder, protected by the shared
access key screen.

## Access

The page asks only for the shared access key. The key is stored as a SHA-256
hash in the client bundle, not as plaintext.

## Privacy

GitHub Pages is static and public. Use anonymous or synthetic cases only.
